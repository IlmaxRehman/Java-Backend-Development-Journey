# Java Backend Development Journey

A practical learning repository documenting my journey towards becoming a Java Backend Developer.

This repository contains independent Java programming exercises, Data Structures and Algorithms, SQL practice, and backend development preparation.

## Tech Stack

- Java 21
- SQL / MySQL
- Git and GitHub
- VS Code
- Maven (as backend development progresses)
- Spring Boot (upcoming)

## Repository Structure

| Directory | Contents |
|---|---|
| `java-fundamentals/` | Core Java concepts and coding exercises |
| `dsa/` | Data Structures and Algorithms in Java |
| `sql/` | SQL queries and database exercises |
| `mini-projects/` | Practical Java applications |

## Development Approach

I follow a build-first approach:

1. Understand the concept.
2. Solve coding exercises independently.
3. Implement practical applications.
4. Debug and improve the code.
5. Document my learning and implementation.

## Goal

Build strong Java programming and backend engineering skills and develop production-oriented backend applications.
